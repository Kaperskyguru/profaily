FAQ

Profile Manager, explained.

Profile settings differ across social networks. Here’s what to expect.

Which profile details can I update?

Profile Manager is designed to update profile images and other supported profile information. Exact fields depend on the connected platform and the permissions it provides.

Can I update every connected account at once?

You choose which connected profiles to include in an update. The change can only be applied to accounts and fields supported by each platform.

Can I track whether an update went through?

Yes. Profile Manager is designed to track updates across the selected accounts so you can see where the change was applied and where follow-up may be needed.

Does each platform allow the same profile changes?

No. Platforms expose different profile fields and update permissions. What you can change may vary by network, account type, and authorization.
